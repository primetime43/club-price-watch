CLUB PRICE WATCH — WINDOWS OUTPUT

Clubs come from recorded item locations. Build from source/ with npm ci, npm run check and
npm run release. Full release needs .NET 8 SDK; native execution needs .NET 8 Runtime.

Start with Start Club Price Watch.bat in the repository root (two folders up).
Keep its server window open. Its S option sets up the generated extension.
Never move a loaded extension folder. Reload after building and refresh app/BJ’s pages.

Outputs are generated in BrowserExtension/ and tools/. No weekly task is installed.
Legacy uninstall is an explicit old-task cleanup, not verification.
Do not include profiles, captures, logs or user data in a distribution.
