# Security and privacy

This self-hosted app has no application-level authentication. Restrict network access
or protect it separately. CORS/extension-origin checks do not make an instance private.

Never post credentials or exploit/account details in public issues, PRs or screenshots.
Use GitHub private vulnerability reporting if enabled for the released repository.
If unavailable, ask for a private channel without including sensitive information.

BJ’s owns login and verification. Never collect sessions, add cookie/debugger permissions,
bypass restrictions or claim observed endpoints are a supported public API. Keep backups.

Review source, Git metadata/history, branches/tags, issues/PRs, Actions logs/artifacts and
container layers before releasing. A sanitized source snapshot does not certify artifacts
previously published elsewhere.
